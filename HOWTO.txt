
STEP 4: Pseudo-3D theta-modes (m,k,eps)

1) Copy files into your tree:
   - include/modes.hpp  -> <repo>/include/
   - src/modes.cpp      -> <repo>/src/
   - configs/run2d_modes.yaml -> <repo>/configs/
   - viz/check_modes.py -> <repo>/viz/

2) Edit CMakeLists.txt to compile modes.cpp into the zpinch library:
   Find the 'add_library(zpinch ...)' block and add: src/modes.cpp
   Example:
     add_library(zpinch
       src/grid.cpp
       src/state.cpp
       src/physics.cpp
       src/riemann.cpp
       src/reconstruction.cpp
       src/time_integrator.cpp
       src/boundary.cpp
       src/io.cpp
       src/utils.cpp
       src/modes.cpp)   # <--- add this line

3) In src/physics.cpp (run_2d_mhd_toy):
   Add near the top:
     #include "modes.hpp"

   Right AFTER 'init_problem(F, cfg, mhdcfg);' insert:
     // ---- Step 4: seeding pseudo-3D modes (if enabled in YAML) ----
     // Minimal parser: we read from the same YAML you pass on argv.
     // If your main already parsed 'modes' block, just wire those values;
     // otherwise this hard-coded example mirrors configs/run2d_modes.yaml.
     {
         // Fallback defaults; if you have access to parsed RunConfig,
         // replace with that.
         const bool enable = true;   // mirror configs/run2d_modes.yaml:modes.enable
         if (enable){
             const int    m  = 1;
             const double k  = 40.0;      // 1/m
             const double eps= 1e-4;
             const double r0 = 0.3;       // frac of Rmax
             const double sg = 0.05;      // frac of Rmax
             const bool seed_vr  = true;
             const bool seed_bth = false;
             modes::seed(F, cfg, m, k, eps, r0, sg, seed_vr, seed_bth);
         }
     }

   If you have your YAML reader already exposing mode params in RunConfig,
   call modes::seed(...) with those values instead of the literals.

4) Rebuild and run:
   cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
   cmake --build build --config Release
   build/Release/zpinch_run.exe configs/run2d_modes.yaml

5) Post-process:
   py viz/check_modes.py
   -> prints a rough growth rate gamma from FFT along z at the ring r=R0.

Notes:
- This seeding is a "proxy": m only sharpens the radial envelope.
- For real θ-modes you'd need full 3D (or dedicated linear MHD solver).
- Keep eps small (1e-4 .. 1e-3) to stay in linear regime.
